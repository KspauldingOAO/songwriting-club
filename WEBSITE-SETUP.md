# Songwriting Club website

Leader: Mrs. Spaulding and Ensemble.

## Enable the website
In repository Settings > Pages, choose Deploy from a branch, then main and / (root), and Save. GitHub will show the published address when deployment finishes.

## Contents
index.html contains the 18-Friday digital songwriting workbook, genre experiments, jingle writing, portfolio, original prompt spinner, four-bar synthesized chord lab, and geometric album cover designer. There are no required accounts or paid trials for the built-in tools. Audio begins only after pressing Play in The Studio. The decorative record on the notebook header is an animation.

## Saving
Writing is stored in the same browser and device. Export a backup regularly and before switching devices; import restores that backup. Browser data can be cleared or unavailable in embedded contexts. The notebook does not submit to Canvas or sync across devices. Submit exports or requested work through Canvas. Cover settings and shuffled prompts are not saved: download cover PNGs and copy prompts to the Idea Vault. Do not use a shared browser profile for private drafts.
